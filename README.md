# Unit Control

## Functionality

This mod gives you the ability to set whether player units, guests, and enemy units are player-controlled or controlled by AI.

Possible uses:

- Control pesky guests that love to cuddle up close to Ultima casting assassins.
- Take full control of every unit and let a friend control the enemy team to make battles more difficult.
- Let the game's AI control every unit to see if your party can win a battle without you driving them.
- Let the game's AI control your party and you control the enemy units, to see if you are capable of winning against your own team.

## Usage

- Ensure that you have [Reloaded-II](https://github.com/Reloaded-Project/Reloaded-II) installed and have registered the game FFT - The Ivalice Chronicles itself in Reloaded-II. (Quick Start guide for Reloaded-II can be found here: [Quick Start](https://reloaded-project.github.io/Reloaded-II/QuickStart/))
- Drop the .7z file into Reloaded-II, then enable it.
- Use the ImGui menu key (defaults to Insert) to open the FFT Mod Loader overlay, then select Mods -> Unit Control to open the overlay.
